## x

x is a system that hosts languages. Scheme, Kernel, Logo, a POSIX shell,
Python, awk and C each load as a library over a small fexpr core that is
never modified to make room for them.

- **[x-lang](https://github.com/jonruttan/x-lang)** — the language, and where to start. [Documentation](https://jonruttan.github.io/x-lang/).
- **[x-os](https://github.com/jonruttan/x-os)** — the languages as a system: a container and a bootable image.
- **Engines** — [x-engine-c](https://github.com/jonruttan/x-engine-c), the reference engine, on [x-expr](https://github.com/jonruttan/x-expr); [x-engine-rust](https://github.com/jonruttan/x-engine-rust), a second.
- **Languages** — [x-r5rs](https://github.com/jonruttan/x-r5rs), [x-r7rs](https://github.com/jonruttan/x-r7rs), [x-krn](https://github.com/jonruttan/x-krn), [x-sweet](https://github.com/jonruttan/x-sweet), [x-logo](https://github.com/jonruttan/x-logo), [x-python](https://github.com/jonruttan/x-python), [x-ash](https://github.com/jonruttan/x-ash), [x-awk](https://github.com/jonruttan/x-awk), [x-cc](https://github.com/jonruttan/x-cc).
- **Tools** — [x-grep](https://github.com/jonruttan/x-grep), [x-sed](https://github.com/jonruttan/x-sed), [x-make](https://github.com/jonruttan/x-make), [x-coreutils](https://github.com/jonruttan/x-coreutils), [x-git](https://github.com/jonruttan/x-git), [x-ssh](https://github.com/jonruttan/x-ssh), [x-tmux](https://github.com/jonruttan/x-tmux), [x-browse](https://github.com/jonruttan/x-browse).
- **Games** — [x-infocom](https://github.com/jonruttan/x-infocom), [x-chess](https://github.com/jonruttan/x-chess), [x-roguelike](https://github.com/jonruttan/x-roguelike).

Writing about it, and two series worked in it, are at
[jonruttan.github.io](https://jonruttan.github.io/).
